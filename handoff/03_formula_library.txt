# PART 6 — FORMULA LIBRARY

Proven skeletons. Each is a **starting point**, not a cage (§0.8). Match a video to a skeleton *and then* judge execution (§3) — a skeleton followed poorly still fails. Formula entries carry only **format-specific** execution notes; universal execution lives in §3.

## §5.0 The reusable format template

Document every format — existing or newly promoted — in this structure. It's what lets the assistant hold a format loosely instead of over-generalizing or overfitting.

```
FORMAT NAME
- Auto-question: the question the frame opens in the viewer for free (§1.2)
- Engine questions → goals: the spawned questions and which goal each loads
- Invariant: the small set that must be true or it isn't this format
- Free to vary: length, register, payoff type, reveal structure, who/what's compared
- Tightness: Loose (wide goal range) / Medium / Tight (mechanic commits the goal)
- Promise + tension mechanisms (§4)
- Why it works (psychological, not "it matches the formula")
- Goal profile:
    · Observed (real data): what a specific instance actually did — one data point
    · Format range: what the container can do across goals when loaded well
- Relatability-breadth note: how broad the setup can go, and the ceiling that implies (§3.1)
- Format-specific execution make-or-break (NOT universal §3 items)
- Load toward another goal: what to weave in for Views / Growth / Sales
```

## §5.1 This vs. That (VS / Comparison) — *worked example of the template*

- **Auto-question:** the instant you imply "this vs ___" and delay the "that," the viewer's brain generates for free: *what's the difference? what's it compared against? which is better? do I relate? have I experienced one or both?* The frame manufactures the gap — you don't build it.
- **Engine questions → goals:** "which is better?" → judgment/authority (**Sales**). "do I relate / which am I?" → identity/tribe (**Growth**, shares). "what's the difference?" → curiosity (**Views**). Which one the **delivery answers** sets the primary goal.
- **Invariant:** two things placed in comparison; the second withheld or shown *after* the first; resolution comes from seeing both. *That's the whole invariant.*
- **Free to vary:** length (5s "girl dog vs / boy dog" ↔ 60s teardown); register (humor skit ↔ serious education); payoff (laugh / lesson / transformation / hot take); reveal structure (partial-withhold / instant-both / live split-screen); who or what is compared.
- **Tightness:** **Loose** — wide goal range; loadable toward almost anything.
- **Mechanisms:** Promise = comparison (often + withheld reveal). Tension = comparison anticipation + introspection. Drivers = binary simplification, completion compulsion, tribal identity.
- **Why it works:** the comparison frame is *incomplete until both sides show*, so the brain can't rest — a viewing guarantee generated by two words. "Amateur vs Seasoned" also triggers introspection ("do *I* do the amateur thing? 'amateur' implies it's wrong — what's better?"), which is self-referential curiosity on top of the base gap.
- **Goal profile:**
  - *Observed:* an "Amateur vs Seasoned designer" cut performed as an all-three (retention + problem-awareness + a clean bridge), and was cited by inbound leads.
  - *Format range:* genuinely all-three, but the *sub-type* you choose leans the goal — Humor/Relatable VS (Views/shares), Educational/Professional VS (authority/Sales), Lifestyle/Identity VS (Growth/tribe), Transformation VS (Views + aspiration), Controversial VS (Views + debate). Same container, different load.
- **Relatability breadth:** the single biggest ceiling lever here. Broader pairing = higher ceiling. Universal reference points ("morning vs night person," "girl vs boy dog") scale to millions; niche pairings ("self-taught vs bootcamp React dev") cap lower but hit a righter audience for Sales.
- **Format-specific execution make-or-break:** the two sides must be **legibly, quickly distinct** (if they look/sound the same the comparison collapses); the "wrong"/amateur side must be a mistake the audience actually makes (introspection only fires on self-recognition); **cut immediately after the reveal** — lingering past the gap-close bleeds retention (this is §1.4 applied); reveal structure (withhold-B vs instant-both) chosen to fit — withhold adds a double gap ("who's the other, and what's the difference?"), instant lets viewers pick a side from second one.
- **Load toward a goal:** *Sales* → make the "seasoned/right" side your method + end-card/caption CTA ("want to handle clients like the seasoned designer? download…"). *Growth* → identity pairing + "follow for more [X] tips." *Views* → widen the reference point (§3.1) + a share/tag line ("which are you? tag someone who's definitely the amateur").

## §5.2 Before & After

- **Auto-question:** "what's the finished state?" — plus a mild "we'll see about that" skepticism the hook can invite.
- **Invariant:** a starting state and an end state, end shown after (or interleaved with) start; resolution = seeing the transformation.
- **Free to vary:** length; register (skit ↔ straight reveal); single vs. repeated befores/afters; voiceover-why or silent; subject.
- **Tightness:** **Loose** — very wide; one of the most niche-agnostic formats.
- **Mechanisms:** Promise = transformation + completion. Tension = repeated reveals / withheld final. Driver = Zeigarnik + skepticism.
- **Why it works:** transformation promises a guaranteed payoff and invites a mild challenge; each before/after re-opens a small gap.
- **Goal profile:**
  - *Observed:* one skit-style "logos I saved" cut did ~100K views, ~60 follows, no direct leads — a Views/warming result *for that instance*.
  - *Format range:* wide. That one video being weak for leads does **not** cap the format (§0.6) — loaded with stakes, education, social proof, and a bridge it can drive Sales; kept light and broad it's a pure Views/warming play.
- **Relatability breadth:** broader = better, strongly. The wider the audience who relates to the *thing* being transformed, the higher the ceiling — a universal transformation (messy→clean room) scales past a niche one (logo redesign).
- **Format-specific execution make-or-break:** the before and after must be **visually unmistakable** (weak visual distinction kills it); hook drama scales the ceiling ("logos I saved" < "the worst logo I've seen, and how I saved it" < "client paid \$5K for this disaster — watch me fix it"); if teaching, the *why it was bad* is the added value.
- **Load toward a goal:** *Sales* → add stakes ("this was costing them \$10k/mo"), show what you changed, bridge to offer. *Growth* → "follow for more rescues / part 1 of…". *Views* → widen the subject + a "what do you think?" comment prompt.

## §5.3 Piggyback Authority (Stitch-Correction)

- **Auto-question:** "is that viral claim actually true?" + observational anxiety ("am I the only one who noticed?").
- **Invariant:** stitch/reference a claim → withhold the correction → deliver a contradicting truth with evidence.
- **Free to vary:** topic; tone; length; closer.
- **Tightness:** **Medium** — leans Views/authority; Sales must be actively welded on.
- **Mechanisms:** Promise = correction/contradiction. Tension = contextual delay. Drivers = borrowed virality + cognitive completion + tribal identity.
- **Why it works:** the stitch inherits the original's audience and the algorithm serves it to everyone who engaged the original; gap + correction = completion satisfaction ("I learned the *real* truth"); a tribal closer turns comments into low-stakes warfare.
- **Goal profile:**
  - *Observed:* 650K views, 160 follows (0.025%), 0 sales — the canonical "great at Views + authority, useless at Sales" case (§0.5).
  - *Format range:* strong Views/authority ceiling; Growth and Sales are weak *unless* deliberately welded on (ongoing-value promise; offer + CTA + positioning).
- **Relatability breadth:** inherited from the original video's topic — you're borrowing its audience, so breadth = the original's breadth.
- **Format-specific execution make-or-break:** the correction must feel like genuine insider knowledge, not a guess; the delay must build, not stall; the tribal closer must be natural.
- **Load toward a goal:** *Sales* → authority line + bridge ("this is the read I do for clients") + CTA/lead-capture; accept a possible reach tradeoff. *Growth* → "part 1 of things about X," tease tomorrow.

## §5.4 Them vs. Me

- **Auto-question:** "what do other pros do that this one won't — and would *I* want that in someone I hire?"
- **Invariant:** a stance the creator takes *against* common practice, with reasons that implicate the viewer's own preferences.
- **Free to vary:** number of items; how hot the hook (swear/controversy if brand voice allows); length.
- **Tightness:** **Medium** — naturally Sales + Views; Growth welds on easily.
- **Mechanisms:** Promise = stated stakes/juicy tea + differentiator. Tension = list-with-reasons / storytelling. Drivers = authority-through-stance + controversy.
- **Why it works:** promises insider "stuff other designers do that I won't" *and* "why you shouldn't want it either" — involving the viewer and pre-qualifying the right audience while repelling the wrong one; provokes other pros to argue (engagement).
- **Goal profile:**
  - *Observed:* directly cited by inbound leads — Sales-primary — while also driving Views (swear-word hook) and Growth (follow CTA).
  - *Format range:* Sales + Views strong; the strongest all-three because the *delivery is the differentiator*, so reach audience = right audience.
- **Relatability breadth:** moderate — scoped to people who hire/care about your field, which is *good* for Sales (righter audience) even though it caps raw reach.
- **Format-specific execution make-or-break:** the stance must be genuinely held and specific; controversy must fit brand voice or it reads try-hard; "what I do instead" must land as a real value prop.
- **Load toward a goal:** already Sales-native; *Growth* → "follow to go from doormat to seasoned designer"; *Views* → hotter hook + a line other pros will argue with.

## §5.5 Results Flip (Behind-the-Scenes Data Reveal)

- **Auto-question:** "why is she showing me these (worse) numbers? something's coming."
- **Invariant:** show real results, set up a comparison, run the metrics the "wrong" direction, then flip to the one that matters — explain *why*, hide *how*.
- **Free to vary:** niche (universal), the metric, length.
- **Tightness:** **Tight** — the withhold-the-*how* mechanic *is* a sales engine; it commits the format to Sales/authority.
- **Mechanisms:** Promise = data/gotcha. Tension = progressive contradiction. Drivers = visual authority + Zeigarnik + authority-through-withholding.
- **Why it works:** pointing at real data signals proof not theory; falling metrics build tension ("why show failure?") so the flip lands harder; giving the principle but not the method proves expertise while leaving the viewer needing you.
- **Goal profile:**
  - *Observed:* Sales-primary in use.
  - *Format range:* narrow by design — Sales/authority. Universal across niches ("fewer workouts, better results"; "lower ad spend, higher ROI") because the engine is counterintuitive *real* results.
- **Relatability breadth:** the *principle* is broad even when the niche is narrow — frame the takeaway universally ("most chase everyone and make nothing; this client focused on 10% and made \$100K more") to widen reach without losing the Sales load.
- **Format-specific execution make-or-break:** data must read as real; tone must telegraph the twist without giving it away; the "worse" stretch long enough to build, not so long it loses people; the withhold must leave genuine value for the offer.
- **Load toward a goal:** Sales-native; *Views* → a more salacious hook + universal takeaway framing; *Growth* → "tomorrow: the exact changes we made / part 1 of…".

## §5.6 Contradiction / Defiance

- **Auto-question:** "why *shouldn't* I do that? now I want to see it done."
- **Invariant:** a prohibition or impossibility stated → defied → a result that vindicates the defiance.
- **Free to vary:** niche; length; whether an earworm/nonsense audio rides along.
- **Tightness:** **Loose** — Views/Growth across almost any niche.
- **Mechanisms:** Promise = prohibition/reactance + transformation. Tension = "why shouldn't I?" + the process. Drivers = reactance + vicarious rebellion.
- **Why it works:** "don't" triggers rebellion — a stronger pull than "look at my pink bathroom"; watching someone break the rule satisfies it vicariously; a catchy/nonsense audio adds a memorable earworm (the pink-bathroom case hit ~7.9M).
- **Goal profile:**
  - *Observed:* Views + Growth (personal-account example).
  - *Format range:* strong Views via reactance; Growth with an ongoing-value promise; can carry Sales when the "impossible" thing is your offer ("there's no way you can build brand + site in a month" → prove it) — an authority-crusher *if the proof is real*.
- **Relatability breadth:** the prohibition must map to something the audience secretly *wants* — the broader that desire, the higher the ceiling.
- **Format-specific execution make-or-break:** the "don't" must target a real desire (reactance only fires if they want the forbidden thing); the pause must let the prohibition land; the result must clearly vindicate.
- **Load toward a goal:** *Sales* → make the forbidden thing your offer/method + prove it. *Growth* → "follow for more rules I break." *Views* → broaden the desire + earworm audio.

## §5.10 Promotion rule (growing the library)

A new skeleton earns a place only when it **recurs across multiple unrelated videos**, not from a single clever one-off. When you spot a repeating structure, write it up in the §5.0 template (auto-question → engine→goals → invariant/free → tightness → mechanisms → why → observed vs. range → breadth → format-specific execution → goal-loading) and, if the board is connected (§0.9), add it there. One-offs are craft flourishes — note them, don't promote them until they repeat.
